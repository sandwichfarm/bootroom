<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client (browser) → /api/config | Loopback-only by default; returns server-side projection of operator-authored config. |
| AppState.loaded_config RwLock | Read-locked per request; written only by the watcher (Plan 06). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07-01 | Information disclosure | /api/config returns config contents | accept | Per RESEARCH Security Domain V8: `bootroom.toml` is operator-authored content readable by anyone with HTTP access. Loopback default mitigates remote exposure. Documented as "do not embed secrets in bootroom.toml". |
| T-03-07-02 | DoS (slow consumer) | RwLock contention | mitigate | Many readers OR one writer; `/api/config` reads are fast (~ms for the projection); the watcher writer happens at most once per debounce window. No lock-starvation possible. |
| T-03-07-03 | Tampering (truncated projection) | projection helper shape drift | mitigate | Single canonical helper `watcher::project_loaded_to_json` is used by both /api/config AND WsMessage::ConfigUpdate (Plan 08). Two consumers, one source — drift impossible by construction. |
| T-03-07-04 | DoS (memory) | very large config projection | accept | bootroom.toml size is operator-chosen; the projection is `O(actions + scenarios + assertions)`. No remote DoS surface on loopback. |
| T-03-07-05 | Confused deputy | /api/config inheriting wrong headers | mitigate | Test `coop_coep_present` asserts the middleware stack still applies (axum's layer model auto-applies to new routes; regression check is the safety net). |
</threat_model>
