    - `decode_bytes_escape("abc\\")` → `Err(EscapeError::TrailingBackslash { pos: 3 })`.
    - `decode_bytes_escape("\\x4")` → `Err(EscapeError::ShortHex { pos: 0 })` (only one hex digit available).
    - `decode_bytes_escape("\\q")` → `Err(EscapeError::UnknownEscape { pos: 1, ch: 'q' })`.
    - Non-ASCII UTF-8 literals pass through byte-for-byte: `decode_bytes_escape("é")` returns the 2-byte UTF-8 encoding `[0xc3, 0xa9]`.

  </behavior>
  <action>
    Create `crates/bootroom-core/src/escape.rs` per RESEARCH Pattern 4. Implementation rules (no fenced code in plans; specifying signatures only):

    - `pub fn decode_bytes_escape(s: &str) -> Result<Vec<u8>, EscapeError>` — iterates `s.as_bytes()` byte-by-byte; on `b'\\'` consumes the escape; otherwise pushes the byte.
    - `#[derive(Debug, Clone, PartialEq, Eq)] pub enum EscapeError` with variants: `TrailingBackslash { pos: usize }`, `UnknownEscape { pos: usize, ch: char }`, `ShortHex { pos: usize }`, `BadHex { pos: usize }`. Implement `Display` so messages read like `"unknown escape '\\q' at byte 1"`, `"trailing backslash at byte 3"`, `"truncated \\xNN escape at byte 0 (need two hex digits)"`, `"invalid hex digit at byte 5"`. Implement `std::error::Error` (auto via Display + Debug).
    - Helper `fn hex_digit(b: u8) -> Option<u8>` accepts `0-9`, `a-f`, `A-F`.
    - For `\\xNN`: if `i + 3 >= bytes.len()` → `ShortHex { pos: i }` where `i` is the backslash position; if either hex digit is invalid → `BadHex { pos: i + 2 }` or `pos: i + 3` (the FIRST invalid one — keep `BadHex { pos: i + 2 }` when h1 fails, `pos: i + 3` when h1 ok but h2 fails).
    - For `UnknownEscape`: `pos: i + 1` (the offending char position, not the backslash); `ch` is the byte cast to `char`. Only ASCII escape characters reach this branch so `as char` is safe; if `bytes[i + 1] >= 0x80` (start of a multi-byte UTF-8 escape continuation), the iteration model handles it as an error too — emit `UnknownEscape { pos: i + 1, ch: '?' }` for non-ASCII follow-up bytes (test it).
