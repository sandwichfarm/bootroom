```rust
async fn check_headers() -> Check {
    use tower::ServiceExt;
    use axum::{body::Body, http::Request};
    use std::sync::Arc;
    let kernel = std::env::temp_dir().join("bootroom-doctor-noop");
    let state = Arc::new(crate::AppState::new_for_test(kernel, None));
    let app = crate::build_router(state);
    let resp = match app
        .oneshot(Request::builder().uri("/").body(Body::empty()).unwrap())
        .await
    {
        Ok(r) => r,
        Err(e) => return Check {
            name: "headers".into(),
            status: CheckStatus::Fail,
            detail: format!("router oneshot failed: {e}"),
        },
    };
    let coop = resp.headers().get("cross-origin-opener-policy")
        .and_then(|v| v.to_str().ok()).map(str::to_owned);
    let coep = resp.headers().get("cross-origin-embedder-policy")
        .and_then(|v| v.to_str().ok()).map(str::to_owned);
    if coop.as_deref() == Some("same-origin") && coep.as_deref() == Some("require-corp") {
        Check { name: "headers".into(), status: CheckStatus::Pass,
            detail: "COOP=same-origin, COEP=require-corp on /".into() }
    } else {
        Check { name: "headers".into(), status: CheckStatus::Fail,
            detail: format!("expected COOP=same-origin, COEP=require-corp; got COOP={coop:?}, COEP={coep:?}") }
    }
}
```

## Trust Boundaries

| Boundary | Description |
|---|---|
| `--config` file → LoadedConfig parser | Operator-supplied TOML enters the canonical loader. Same boundary as `bootroom check`. |
| filesystem → in-process router | `build_router(state)` is run with `new_for_test` (no real kernel file required). Doctor binds nothing externally. |
| chromium subprocess `--version` output | Captured into the human/JSON detail string. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-05-04-01 | Tampering | Crafted bootroom.toml via `--config` | accept | Reuses `LoadedConfig::load_from_str` — same surface as `bootroom check`. No new attack surface. [V5/V12 ASVS — control inherited from Phase 3.] |
| T-05-04-02 | Information Disclosure | `--config <secret-path>` echoed in stderr summary | accept | Operator supplies the path; appearing in error output is expected (same posture as `bootroom check`). Local dev tool. |
| T-05-04-03 | Tampering | Chromium binary at $PATH-discovered location runs with `--version` | mitigate | `discover_chromium` (Phase 4) uses pure-Rust `$PATH` walking — no `which` shell-out. `Command::new(path).arg("--version").output()` is safe (no shell interpolation). |
| T-05-04-04 | Denial of Service | Chromium `--version` hangs | mitigate | `Command::output()` is synchronous and bounded by chromium itself (--version is sub-100ms in practice). If pathologically slow, doctor blocks but does NOT corrupt state. Future plan: add a tokio::time::timeout wrapper if reports come in. Accept for v1. |
| T-05-04-05 | Information Disclosure | JSON output includes file paths | accept | Operator's machine, operator's paths. Local tool. |
| T-05-04-06 | Tampering | Embedded qemu-wasm-rev.txt content can be anything | accept | Build host trust boundary already applies. Doctor displays verbatim with no interpretation. |
| T-05-04-07 | DoS | Header self-check hangs on `oneshot` | mitigate | `tower::ServiceExt::oneshot` against an in-process router has no network, no I/O — bounded by router logic. No timeout needed for v1. |
</threat_model>
